U.S. Airline Flights Analysis (2010 to 2011)

This Tableau project analyzes U.S. airline flight data from 2010 and 2011 to identify trends in flight activity, delays, cancellations, airports, and airlines.

The project answers the following questions:
1. Why do flight totals appear to drop significantly from 2010 to 2011?
2. Which holidays experience the lowest flight activity?
3. Which airline operates the most flights each week?
4. Which airports have the most cancelled flights?
5. Which states experience the longest departure delays?
6. How do flight cancellations compare between 2010 and 2011?

Skills Demonstrated:
* Data Visualization
* Data Analysis
* Tableau Dashboards
* Geographic Mapping
* Business Intelligence Reporting
